Send a capture in three steps

There's nothing to install on your network. If you can save a file from Wireshark, you can send us a capture.

In Wireshark, choose File › Export Packet Dissections › As CSV

What we look for

Every capture is checked for two attacks. Matches are grouped by day, so one noisy afternoon shows up as one finding instead of hundreds.

Check active ARP

ARP poisoning

A device answers for IP addresses that aren't its own, usually your router's, so traffic meant for other machines passes through it first.

Flagged when
One MAC address claims two or more IP addresses on the same day.
You see
The MAC address, how many packets it sent and when it started.
Check active TCP

SYN flood

A burst of connection requests that claim to come from the machine they're sent to, aimed at one port to tie it up.

Flagged when
A packet carries the [SYN] flag and its source and destination IP match.
You see
One row per port per day, with the number of packets.

About this project

LAN Sharks started as the capstone for the Python Scripting Fundamentals course in the Akamai Network Engineering Professional Certificate.

The company is made up, but the detection code is real. Python scripts read each capture, store every packet in SQLite and run both checks whenever a customer logs in.

  • Python 3
  • SQLite
  • CGI
  • HTML, CSS and JavaScript
  • No frameworks
